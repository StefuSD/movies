# Stefu Movies — данные

Общий каталог фильмов и сериалов для приложения Stefu Movies.

- `catalog.json` — каталог, 1462 записей
- `covers/` — обложки, имя файла совпадает с полем `cover` записи

Приложение читает эти файлы напрямую, без токена и авторизации,
поэтому репозиторий должен оставаться публичным.

Личные данные пользователей — оценки, комментарии, история просмотров —
здесь не хранятся. Они лежат только на устройстве каждого пользователя
и в обмене с сервером не участвуют.
